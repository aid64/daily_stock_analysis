## 〇、本轮调研的决定性发现（改写全部优先级）

### 发现 1：PIT 数据管道半瘫痪（根因，P0）

实测 `data/pit/convertible_pit.parquet` 逐日截面数：

| 日期 | 截面券数 |
|---|---|
| 2026-09-01 | 300 |
| 2026-09-02 | 297 |
| 2026-09-03 | **56** |
| 2026-09-08 | **56** |
| 2026-09-09 | **17** |

`update_pit_tail.py --limit 50`（daily_pipeline 挂的参数）每天只滚动更新 50 只，全市场 914 只永远追不上。**这不是转债市场萎缩（raw 缓存 914 只、9 月初截面仍有 300 只），是增量管道覆盖断裂。**

### 发现 2：传导链完整闭合——"数据不更新"的完整解释

```
PIT 截面 300→56 只
  → min_candidates=15 过滤后池仅 3-6 只 < 15
  → pit_snapshot_picks 返回空（"让位现金"）
  → compute_cb_target_weights 空
  → record_quarterly 抛 "2026Q1 内无调仓计划"
  → current_plan.json 冻结在 2025-10-09（11 个月前）
  → 操作单每天渲染旧计划（含已退市 123089，20% 权重）
  → 用户看到"股票数据没有更新"
```

### 发现 3：强赎数据已入库但从未被消费（P0）

- Tushare `cb_call` 一手实测（15000 积分账户）确认：**123089.SZ 于 2025-09-16 公告实施强赎、2025-10-15 赎回、2025-10-23 退市**。
- `data/pit/cb_calls.parquet`（2948 行）**早已包含该记录**，但 `pit_snapshot_picks` / `export_current_plan` / DSA 操作单全链路**没有任何一处消费它**。
- 2025-10-09 调仓之所以买入一只已公告强赎 23 天的债：PIT 行情在退市前仍是"有效价格"，纯价格过滤无法拦截——**必须用 cb_call 生命周期事件硬阻断**。

### 发现 4：三表机器已修好且能跑（资产，非缺口）

`run_paper_tracking.py --record --quarter 2025Q4` 实跑成功：期末 10,034.73（+0.35%，回撤 1.68%），equity_curve / fills_vs_plan / cost_vs_model 三表正确落盘。之前"三表无产出"的判断已过时——卡点只在 2026 季度因发现 1/2 无法回放。

### 发现 5：策略层的真实状态（不变，但有了更准确的归因）

| 结论 | 状态 | 关键数字 |
|---|---|---|
| 月频双低基线 | 1×成本 +15.7%/回撤 25.4%，2×成本 **-22.0%** | 成本悬崖 |
| 季频双低 | 1× +14.6%/回撤 14.8%，2× **-2.1%** | 最接近可行但未过门 |
| 双低因子 | **crowding_silent**（2025 起 IC≈0，离散度未坍缩） | 退出主策略 |
| E1 复合因子 | **fail**（四臂全负，超额仅 0.35pp） | 关闭 |
| E2 估值择时 | **pass**（回撤 14.8%→10.2%，改善 31%） | 保留为仓位层 |
| E3 下修事件 | **fail**（超额 -0.56%） | 关闭 |
| F8 止损带 | **fail**（回撤反增 2.1pp） | 关闭 |
| ytm_true | 分年 IC 稳定为正（含双低死亡年） | 唯一接班候选，待预注册验证 |

**重要修正**：此前把"2026 年组合空转 11 个月"归因为"候选池萎缩（市场性）"，本轮实测证明**主因是 PIT 数据断裂（工程性）**——2026 年若数据管道健康，每季仍有 200+ 只截面、基础双低过滤后池是充足的。策略结论（成本悬崖、双低失效）不受影响，但"策略已无标的可选"的说法不成立。

## 一、终局架构（Final Architecture）

```
┌─────────────────────────────────────────────────────────────┐
│                     数据地基（quant_research）                │
│  Tushare 15000分: cb_daily/cb_call/cb_share/cb_basic/cb_rate │
│  akshare 兜底: bond_zh_cov_value_analysis                    │
│  PIT 三层: raw(914券) → convertible_pit.parquet → 生命周期层  │
│  ⚠ 新增: cb_call/cb_basic 生命周期合并进导出链（强赎/退市阻断）│
└──────────────┬──────────────────────────────────────────────┘
               ↓ (唯一契约: current_plan.json + schema版本)
┌──────────────┴──────────────────────────────────────────────┐
│                决策层（quant → 单一候选路径）                  │
│  季频双低(冻结参数) × E2估值择时(仓位乘数) × 生命周期硬阻断      │
│  输出: targets{symbol:weight,t1_close} + blocked_symbols+原因  │
│  预注册中: ytm_true 接班实验（唯一新增研究线）                  │
└──────────────┬──────────────────────────────────────────────┘
               ↓ (唯一文件契约，跨项目不互相 import)
┌──────────────┴──────────────────────────────────────────────┐
│              执行层（daily_stock_analysis）                    │
│  Decision Snapshot(版本化) → 操作单(限价+放弃条件) → 飞书单通道 │
│  /操作单 /持仓登记 /成交回填 /对比 /健康（双向命令）            │
│  通知总线: logical_id 替换语义 + 标的级告警聚合 ✅(已实现)       │
│  ⚠ 新增: 快照新鲜度门槛(数据过期→拒绝生成买单)                 │
└──────────────┬──────────────────────────────────────────────┘
               ↓ (人工在券商 App 下单)
┌──────────────┴──────────────────────────────────────────────┐
│                     用户 + 真实账本                            │
│  手动下单 → /成交回填 → 模拟vs真实对账 → 月度/季度评估          │
│  影子期指标: 执行率/滑点/漏回填/现金差 → promotion gate         │
└─────────────────────────────────────────────────────────────┘
```

**架构三原则（终局裁定）：**

1. **跨项目只走一个文件契约**（current_plan.json，schema 版本化）——禁止互相 import，禁止第二契约。
2. **任何数据不新鲜就不生成可执行指令**——宁可输出"今日无法执行+原因"，绝不渲染陈旧计划。
3. **用户层只见一张决策包**——一个逻辑事件一条消息（已实现），多策略在研究层竞争、不并行推送。

### 修复（P0——不修好之前一切策略结论都不可信）

1. **PIT 全量覆盖**：`update_pit_tail` 去掉 `--limit 50`（全量 914 只实测约 112 分钟，改为每周日全量+工作日增量优先队列——优先队列机制已实现）。
2. **生命周期硬阻断**：导出计划前合并 cb_calls（公告实施强赎/已赎回/退市）+ cb_basic（delist_date），命中即剔除并记入 blocked_symbols；123089 类事件永不再进操作单。
3. **计划新鲜度门槛**：DSA 生成操作单前检查 `pit_end` 距今 ≤N 交易日、`generated_at` 晚于最近 assemble；过期则输出"信号过期，今日不生成指令"并推 system_error。
4. **2026 三表补录**：管道修复后回放 2026Q1-Q3，把 11 个月空转期补进 paper 记录。

## 三、12 个月路线图（终局版）

### 第 1 个月：数据与安全层（全部 P0，无新增研究）

| 周 | 任务 | 验收 |
|---|---|---|
| W1 | PIT 全量刷新 + 优先队列日常化 | 截面数恢复 250+/日 |
| W1 | cb_call/cb_basic 生命周期合并进 export_current_plan | 123089 被剔除且记录 blocked 原因 |
| W2 | DSA 计划新鲜度门槛 + 过期拒绝生成 | 人工把 pit_end 改旧→操作单显示"信号过期" |
| W2 | 2026Q1-Q3 三表补录 | paper_tracking 目录含 2026 各季记录 |
| W3 | Decision Snapshot 版本化（plan/持仓/现金/订单/成交一体） | /健康 显示快照版本与各数据日期 |
| W4 | 现金登记提醒闭环 + 全链路 regression | 用户 /持仓登记 后操作单给出真实可执行张数 |

### 第 2-3 个月：影子执行期（paper + 人工真实下单并行）

- 每天一张操作单；用户可执行可放弃；/成交回填；
- 影子指标周报：执行率、滑点、漏回填、现金差、版本错配数；
- **期间禁止任何参数修改**（发现 1 的教训：先让管道自己跑 8 周）；
- 月末跑 --record 出三表，与真实账本对账。

### 第 4 个月：ytm_true 接班实验（唯一预注册研究）

- 预注册文档先行（门槛、窗口、N=1）；
- 季频 + 1×/2× 成本 + 生命周期阻断全开；
- fail 即关闭并记录，不调参续命。

### 第 5-6 个月：promotion gate 评估

四硬门槛（全过才进入下一阶段）：

1. 影子期执行率 ≥90%；
2. 预测(三表) vs 实际年化差 ≤5pp；
3. 实际回撤 ≤ 纸面 1.5×；
4. 保守成本档（2×佣金+10bp 滑点）净收益不翻负。

### 第 7-12 个月：按 gate 结果分叉

- **gate 全过** → 小幅扩大：002475 纳入组合风险观察→独立预注册股票低频线→评估半自动审批执行（人工 kill switch 常开）。
- **gate 未过** → 系统定位降级为"个人研究工作台 + 持仓监控器"，保留全部数据/审计资产，停止实盘推进——这本身就是诚实且有价值的结果。

### 恒定不做清单（12 个月内有效）

- 不接真实自动下单；
- 不新增第 2 条研究线（ytm_true 之外）；
- 不恢复多渠道推送；
- 不迁移 backtrader；
- 不做盘中高频/事件驱动交易（E3 已证伪）。
