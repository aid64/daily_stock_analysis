# Triage Labels

本地任务使用以下五种标准状态词汇。

| Skill label | Local label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估。 |
| `needs-info` | `needs-info` | 等待补充信息。 |
| `ready-for-agent` | `ready-for-agent` | 需求已明确，可交给 agent。 |
| `ready-for-human` | `ready-for-human` | 需要人工实现。 |
| `wontfix` | `wontfix` | 不再处理。 |
