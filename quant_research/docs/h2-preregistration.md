# H2 预注册：转债季频调仓结构

> 预注册日期：2026-09-01　｜　状态：**已预注册，未执行**
> 依据：ROADMAP §3.4.1 C1 评估——A1 成本悬崖 + B1 buffer 不足 + ratio=2.0 实质买入持有，指向"未测的中间态：季频结构"。

## 1. 假设

**H2**：将转债双低策略的调仓频率从月频改为季频（每季第一个 PIT 交易日调仓，季内持有不动），能在 **2x 成本下实现非负净收益**，同时年换仓事件 ≤6、年化换手相对月频基线（同窗）下降 ≥50%。

逻辑：换仓事件 3x 减少（12→4 次/年）直接压缩成本暴露；H1 ratio=2.0 已证明"低频持有"形态在 2x 成本下可存活。季频是"月频（成本死）"与"买入持有（H1 ratio=2.0，实质熄火）"之间唯一未测的合法中间态。

## 2. 设计

- **单参数改动**：`rebalance_freq` 月→季（每季首个 PIT 交易日）。选债过滤链、top_n、v2 过滤、min_candidates 全部与月频基线一致（零自由度）。
- 季内持有：非调仓月沿用上季目标（含让位判定——若上季末已空仓，保持空仓至下季调仓日）。
- 对比基线：月频（同参数、同窗）。

## 3. 参数空间（冻结，无扫描）

| 项 | 取值 |
| --- | --- |
| rebalance | 季频（1 档） |
| 其余参数 | 与月频基线逐项一致 |
| 成本档 | 1x, 2x |
| 组合数 | 2（季频 1x/2x）+ 月频基线 2（已由 A1/A2 覆盖，直接引用） |

窗：2020-01-01 → 2025-12-31（与 H1 一致，2026 零敞口年排除；holdout 另计）。

## 4. 验收与拒绝（先写死）

**主验收（全部满足才通过）**：

1. 2x 成本下净收益 ≥ 0；
2. 年换仓事件 ≤ 6（季频结构性满足，形式核验）；
3. 年化换手相对月频基线下降 ≥ 50%；
4. **在市月最大回撤 ≤ 月频基线的在市月最大回撤 + 5pp**（季频的诚实代价检验：持仓暴露于排名恶化更久，回撤不得显著恶化）。

**拒绝条件（任一触发即 H2 失败，不得换回月频调参重试）**：

- 2x 成本下净收益 < 0；
- 换手降幅 < 50%；
- 在市月最大回撤超出基线 +5pp 以上（季频的持有风险失控）。

H2 失败即关闭"频率结构"整条路线（月频已死、季频也死），C1 转向"换标的池（H3）或工具化"。

## 5. 执行

1. `compute_cb_target_weights(rebalance="Q" 语义)`：每季首个 PIT 交易日调仓，季内沿用。
2. 2 次回测（季频 1x/2x）；月频基线数字引用 A1/A2 产物。
3. 输出 `output/h2_quarterly_rebalance.json`；结果写回 ROADMAP。
4. 附带产出：季频的在市/空仓月暴露表（与 A2 同口径，供回撤归因）。
