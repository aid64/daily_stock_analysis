# H1 预注册：成本感知的换手控制（rank-buffer + 最小交易阈值）

> 预注册日期：2026-09-01　｜　状态：**已预注册，未执行**
> 依据：ROADMAP §3.4 B1 + A1/A2 联合结论。本文在跑任何数据之前写定假设、参数、验收门槛与拒绝条件。

## 1. 假设

**H1**：在转债双低月频策略上叠加"持仓缓冲 + 最小交易阈值"，能在**不损害 2x 成本下净收益**的前提下，把年化换手相对 1x 基线降低至少 30%。

逻辑：A1 证明成本是生死线（2x 成本 -37.7pp）；A2 证明在市月均毛利仅 +0.21%。换手是唯一可压缩的大项。外部证据（雪球实盘"跌出前 40% 才换"）支持 rank-buffer 方向。

## 2. 设计（三件套，全部作用于执行层而非选债层）

1. **持仓缓冲（rank-buffer）**：调仓日现有持仓若仍在双低排名 `top_n + buffer` 以内则保留，不做换出；空位由排名最前的非持仓券补足。buffer ∈ {3, 5}（预注册两档，不扫更多）。
2. **最小交易阈值**：目标权重与当前权重差额的市值 < 该券一手成本的 `min_trade_ratio` 倍则跳过该腿。min_trade_ratio ∈ {1.0, 2.0}。
3. **成本惩罚排序（不做）**：候选分数减预估成本的完整版留 H2——H1 先验证前两件套的独立贡献，避免一次引入两个自由度。

## 3. 参数空间（预注册，冻结）

| 参数 | 取值 |
| --- | --- |
| buffer | 3, 5 |
| min_trade_ratio | 1.0, 2.0 |
| 组合数 | 4（+基线共 5 次运行） |

训练/验证窗：**2020-01-01 → 2025-12-31**（A2 已证明 2026 全年零 CB 敞口，纳入只会稀释信号；让位月份照常让位）。

## 4. 验收与拒绝（先写死，后跑数）

**主验收（同时满足才通过）**：

1. 2x 成本下净收益 ≥ 0；
2. 年化换手相对 1x 基线（同窗 2020-2025）下降 ≥ 30%；
3. 在市月收益均值相对基线下降 ≤ 0.10pp（允许小幅让渡毛利换成本）。

**拒绝条件（任一触发即 H1 失败，不得追加参数重试）**：

- 2x 成本下净收益 < 0；
- 换手降幅 < 30%；
- 通过验收的参数组合中，月度收益分布出现基线没有的月亏 > 5%（说明 buffer 引入了新的尾部风险）。

**多重检验控制**：4 个组合全部如实注册；最终报告必须列出全部 4 组结果（含失败组合），N 由实验注册导出。若 4 组全部失败，H1 关闭，不引入第三参数重试。

## 5. 执行计划

1. 实现 `WeightTargetStrategy` 的 buffer/min-trade 执行变体（选债层零改动，`pit_snapshot_picks` 返回 top_n+buffer 完整排名，执行层决定保留/换出）。
2. 5 次运行（基线 + 4 组合）× 1x/2x 成本各一次 = 10 次回测。
3. 输出 `output/h1_turnover_control.json`（全组合结果 + 验收判定）。
4. 结果（含负结果）写回 ROADMAP；通过则进入 B3 六维温度设计与新 holdout 流程。
