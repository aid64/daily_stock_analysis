# ytm_true 接班实验预注册（2026-09-12）

> 依据：OPTIMIZATION-PLAN-V2 批次 C 后的 E1 修正版重跑——ytm_true 单臂 +13.11% 为四臂最强（双低同窗 -30.45%），是唯一存活的候选研究线。
> 纪律：本文档在实验运行前写死全部门槛；实验只跑一次，fail 即关闭并记录，禁止调参续命；N=1 计入 experiments registry。
> 数据边界：训练/验证窗口终点 = holdout 起点（2026-08-08）；holdout 数据只用于最终评估，不参与任何选择。

## 一、动机

- 修正版 E1（PIT 对齐、季频、现金守恒、免印花税）中 ytm_true 单臂总收益 +13.11%，同期双低 -30.45%，超额 +43.6pp；
- D1 真实 YTM IRR 分年 RankIC 稳定为正（2021 +0.067 ~ 2026 +0.110，含双低死亡年），与价格/溢价率部分正交；
- 已知疑点（D2 未闭环）：ytm 与低价/评级的共线性未完全排除——若本质是"短久期低价"，需按风险框架而非 alpha 框架评估。

## 二、实验设计（写死，不得更改）

- **策略**：季度调仓，每季首个 PIT 交易日选 ytm_true 最高 5 只，等权；生命周期硬阻断（强赎/到期/退市/行情缺失）+ 现金闸门全程生效；
- **对照臂**：同引擎同窗口的双低基线（同样无 min_candidates 附加门，与 E1 修正版口径一致）；
- **成本**：真实费率档（万 0.845 + 最低 5）与 2×压力档各跑一次，两档都必须过门；
- **窗口**：2020-01-01 .. 2026-08-08（E1 同窗，保证可比）；holdout 另行最终评估；
- **评估器**：E1 修正版引擎（现金守恒、整手、季度日历年化）——直接复用 `e1_composite_backtest.simulate_rebalance`，不做任何修改。

## 三、预注册门槛（全部满足才 pass）

1. **净收益**：ytm_true 季频总收益 > 双低基线 + 2pp（1× 成本档）；
2. **压力档**：2× 成本档下 ytm_true 总收益仍 > 双低基线（不要求仍 +2pp，但不得翻负）；
3. **回撤**：ytm_true 最大回撤 ≤ 双低基线最大回撤 × 1.1；
4. **分年稳健**：分年收益为正的年份数 ≥ 总年份数的 60%（约 2020-2026 中 ≥4 年），且不依赖单一月份；
5. **共线性检查**（D2 补课）：对 ytm_true ~ price + 剩余期限 做逐期截面回归，残差 IC 分年均值 ≥ 0 且 t 值 > 1.5——证明信息量不止"便宜"。

任一条不满足 → **关闭 ytm_true 线**，记录诚实负结果，当前 plan 维持"无信号/让位现金"状态。
