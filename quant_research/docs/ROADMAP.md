## 〇、核心判断（先说结论）

1. **项目已完成从"脚本式回测"到"研究基础设施"的跃迁，但尚未产出任何可部署策略。** 六层架构、PIT 数据、防前视/防幸存者偏差、过拟合审计均已落地，这部分的工程质量高于多数个人量化项目。
2. **双低因子统计显著，但已不可交易。** 项目实测 RankIC |t| 达 12.8–16.6；而外部实盘证据显示 2026 年双低策略跑输中证转债指数约 5%。因子没死，是容量和成本死了。
3. **最大的未兑现收益不是策略，而是成本与容量研究。** 新基线换手 52.12x，而过拟合审计里最关键的 P0-3（成本 1x/2x/4x 敏感性）**从未执行**。在跑出这条曲线前，任何"因子显著→策略可用"的推论都缺一环。
4. **回测底座依赖 backtrader，而 backtrader 自 2019 年起基本停止维护。** 这是全项目最重的技术债，且被 optional-dependency 的形式掩盖了。
5. **可复现性是当前最薄弱的工程面**：无 lock 文件、无随机种子、依赖全为 `>=` 下界、`pyproject.toml` 声明的 `README.md` 根本不存在。

### 2.2 关键判断：backtrader 停更对本项目的直接影响

独立来源均确认 backtrader 自 2019 年起无重大更新，存在 Python 3.10+ 兼容问题，单线程事件循环在大数据集上很慢，且不适合 A 股生产环境。

**本项目的处境**：`backtest/engine.py`(387 行) 建立在 backtrader 之上，而它承载了全部 WF、网格扫描、两段式回测。这意味着：

- 参数空间探索受限于事件驱动性能（52x 换手的两段式回测、网格扫描都很慢）；
- Python 3.13 环境下存在不可用风险（实测该环境未安装 backtrader）；
- 社区主流做法已是"**研究用向量化（VectorBT/自研 panel），执行用专业框架（vn.py/QMT）**"。

本项目 `core/panel.py` 已经是 date×symbol 矩阵结构——**距离向量化回测只差一层执行模拟**。这是一个被低估的机会：迁移成本比想象中低。

### 2.3 方法论共识（知乎高赞来源汇总）

| 共识 | 要点 |
|---|---|
| **Alpha Source 必须可一句话说清** | 若无法描述赚的是什么钱（趋势/均值回归/波动率溢价/流动性/微观结构定价错误），任何参数组合都只是随机噪声拟合 |
| **参数须有物理意义** | 均线周期代表"平均持仓成本/趋势确认窗口"，而非待求解的数学变量。无解释的参数实盘失效概率接近 100% |
| **高原而非尖峰** | 有效逻辑的参数空间应是宽阔高原；孤立陡峭的最优解几乎可断定是过拟合 |
| **SARA：回测与实盘的状态鸿沟** | 回测状态转移同步/原子/确定；实盘异步/延迟/可重试/可能乱序/部分失败。**很多"看起来像过拟合"的失效，实际死在执行系统** |
| **PIT 是刚需** | 宏观/财务数据发布后会修订，必须用初次披露值；股票池须动态重构，还原退市标的 |
| **多重检验** | 一万随机因子在 5% 水平下靠运气也有 500 个"显著"。须用缩水夏普、控制族系误差率，并对因子做经济学逻辑审查 |
| **因子门槛** | IC>0.05 有效、>0.1 强有效；IR>0.5 是稳定赚钱的底线 |
| **拥挤度衰减** | 小市值因子案例：2017 前 IC 0.08+/IR 1.2 → 2024 后 IR 转负。因子拥挤度飙升后溢价被摊薄 |

2. **月频毛 alpha 极薄**：在市月均仅 +0.21%。任何单月内多出的摩擦（冲击、追单）都可能吞掉整月利润——H1 的最小交易阈值必须按"整手交易成本 / 月均毛利"比例设置。
3. **2026 年是零敞口年**：新基线的正收益全部来自 2020-2025（在市月贡献 +13.4%，空仓月 +1.7% 为残余持仓波动）。与外部证据（2026 双低跑输指数 5%、中位数 170-185）交叉印证——池萎缩让位是规则正确行为。**H1 训练窗必须显式处理让位月份（独立状态或剔除），不能让"空仓月零收益"稀释选参信号。**
4. **在市月胜率 51.4%、月均 +0.21%**：策略本质是"薄利润 × 持续参与"。降换手把"薄利润"变"厚利润"是唯一路径——B1 三件套（buffer/最小阈值/成本惩罚）方向不变，优先级进一步上调。
