# 真钱执行手册（纸面 → 真钱的桥）
> 关联文档：`docs/strategy-compare-deck.md`（运维真源）

> 适用范围：仅 **X_事件套利** 与 **Y_确定性收益** 两通道。主动策略（A/E/F/G/H）未过三关（滚动 60 日跑赢 C + 三窗口切片 + 扣成本为正）之前，本手册对其**不生效**。
> 原则：系统出单 → 人工在券商执行 → 成交后回填。人是执行引擎，系统不做真实下单。

## 一、Y 通道：国债逆回购（最简单的第一笔）

**窗口**：节前最后一个交易日、月末、周四 14:30–15:00（利率冲高时段）。

**券商 App 操作**（以沪市 GC001 为例）：
1. 交易 → 国债逆回购（或直接输入代码 `204001`）
2. 方向选 **"卖出"**（逆回购在行情软件里显示为卖出，这是新手最易踩的坑）
3. 价格：直接挂当前显示的年化价（市价即可，成交即锁定年化）
4. 数量：10 张 = 1,000 元起步；¥12,000 = 120 张
5. 确认后资金冻结，到期（含节假日顺延）本息自动到账，**无需任何反向操作**

**计息注意**：资金可用日 ≠ 计息日。节前做 GC001 按实际占用天数计息（如 9-30 操作，10-09 可用，计息 8-9 天）——这正是节前冲高窗口的意义。

**回填**：成交后向系统发送成交信息（品种/金额/年化/操作日），写入台账 Y 槽。

## 二、X 通道：事件套利（要约收购/现金选择权）

**触发前提（系统已自动核验，人工只需复核）**：
- 全量要约（部分要约一律不做）
- 现价 < 要约价 × (1−2%)（ST 股 5%）
- 要约期限 > 10 个交易日

**人工复核清单（下单前逐项过）**：
1. 打开要约收购报告书全文，确认：要约价、部分/全面、期限、收购人资金来源（"自有资金"优于"并购贷款"）
2. 核对当前可否预受（要约期是否已开始）
3. 估算失败风险：收购人持股比例、反垄断/审批前置条件
4. 确认单笔 ≤ 总资金 10%

**券商操作**：
- 要约期内正常**买入**标的（记录买入价）
- 持有至要约期，**预受要约**：交易菜单 → "预受要约"/"要约申报"，输入要约代码（见公告）
- 若价差中途收敛可提前二级市场卖出（免预受）；未预受部分到期自动解冻

**红线**：*ST 类标的即使价差达标，单笔减半；要约失败=承担全部市场波动。

## 三、主动策略晋升流程（过了三关后）

1. 月度排名报告 → 槽位连续两月满足 promote 标准
2. 提交证据包（三窗口切片/误差条/成本敏感性）→ 用户书面确认
3. 首笔真金 ≤ ¥2,000/槽，走同纸面相同操作单
4. 首笔真实成交后，纸面槽位转为"影子对照"（继续验证滑点假设）

## 四、风控红线（所有通道）

- 不满仓单一通道；真金总额 ≤ 总资金 30% 起步
- 任何"错过窗口"都不构成追价理由
- 系统异常（台账不自洽/审计 FAIL）当日报警，修复前不做新真钱操作
