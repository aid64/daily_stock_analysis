# 文档编写规范（Documentation Standard）

> 本规范从多策略对比盘文档体系的实战迭代（2026-09-28 ~ 10-03，含 4 次结构性返工）中提炼。
> 适用范围：本项目所有新增/修改的 markdown 文档。与 AGENTS.md 互补不冲突。

## 1. 文档分类（先选类型再动笔）

| 类型 | 位置 | 特征 | 例子 |
|---|---|---|---|
| **运维真源** | `docs/` | 系统如何运行、回滚方式、调度细节——**唯一真源** | `strategy-compare-deck.md` |
| **手册** | `docs/` | 面向操作者的步骤指南 | `real-money-playbook.md` |
| **矩阵/清单** | `docs/` | 结构化盘点（数据源/槽位/接口），表格优先 | `data-source-matrix.md` |
| **变更日志** | `docs/CHANGELOG.md` | 扁平条目追加，禁止节标题 | 已有规范 |
| **调研/分析** | `.scratch/`（本地） | 时效性产物，允许迭代重叠，须加索引与过时标注 | `.scratch/dsa-strategy-validation/` |
| **索引** | `docs/INDEX.md` | 场景路由表，新文档必须注册 | 已有 |

**入 `docs/` 的门槛**：内容长期有效 + 有人会回来查 + 不含本地路径/密钥。时效性产物放 `.scratch/` 并在 `README.md` 索引。

## 2. 结构规范

### 2.1 头部三要素（新增文档必须有）
```markdown
# 标题
> 一句话定位 + 建立日期
> 关联文档：`docs/xxx.md`（互相指向，禁止孤岛）
```

### 2.2 章节编号
- 用 `## 1.` `## 2.` 有序编号；**追加新节必须顺延编号，禁止 7a/7a 重复或乱序插入**
- 结构性新增导致编号冲突时，一次性重排全部节号（一次 commit 完成）

### 2.3 必备节（运维类文档）
- **回滚方式**：每个可逆操作写明回滚命令
- **已知局限**：诚实清单——未验证项/假设/边界，"改进前必读"
- **调度细节**：定时任务的触发时点/例外行为（假期/电池/锁）

## 3. 状态管理

### 3.1 状态头注（文档过时时立即加，不等读者发现）
```markdown
> **⚠ 状态更新 YYYY-MM-DD**：本文的 XX 部分已过时（原因），以 YY 为准。
> 保留价值：ZZ 部分（策略决策/调研结论）未变。
```

### 3.2 生命周期
```
草稿(.scratch) → 活跃(docs/，INDEX注册) → 过时(加状态头注) → 归档(git历史可回溯，删文件)
```
- 过时文档**不删文件**加头注即可（git 历史回溯最终归档）
- 平台/渠道死亡时同步标注相关文档（参考 notifications.md 的 P5 后过时标注）

### 3.3 病历制（系统/策略停跑时）
停跑/清仓 → 在运行目录写 `{名称}_postmortem.md`：发现→迭代→失效全过程+代码版本。

## 4. 引用规范

- **交叉引用**：关联文档在头部互相指向；新文档必须在 `INDEX.md` 注册
- **路径引用**：引用的文件路径必须实际存在（提交前 ls 验证）；台账/JSON 内引用的文件路径同此
- **禁止死链**：文档删除/改名时，grep 全 docs/ 更新所有引用

## 5. 写作纪律

1. **表格优先**：结构化信息（槽位/接口/参数/状态）用表格，不用段落堆叠
2. **诚实清单**：每个系统文档必须有"已知局限"节——未验证项/假设/未校准阈值全部写明
3. **时间线标注**：所有结论/数据标注采集日期（"2026-09-30 实测"）；无日期的结论不可信
4. **一文档一真源**：同一事实只在一个文档维护，其他文档引用之（禁止多处更新同一事实）
5. **上下文节约**：闲聊/过程不写进文档；报告类输出的篇幅按场景定，**仅"检查员解读"场景限 5 行内**（见下条），正式报告不受此限
6. **5 行内报告（检查员模式）**：结论一行 + 异常引用 + 休市跳过——**仅适用于检查员对审计脚本（`compare_deck_audit.py`）输出的解读**，不约束个股/大盘/聚合等正式报告

## 6. 提交前检查清单

- [ ] 文档类型选对了吗（docs/ vs .scratch/）？
- [ ] 头部三要素（定位/日期/关联）齐了吗？
- [ ] 章节编号顺延无冲突？
- [ ] 引用的文件路径都存在？
- [ ] INDEX.md 注册了吗？
- [ ] 已知局限写了吗？
- [ ] 过时文档的状态头注更新了吗？
- [ ] CHANGELOG 需要条目吗（用户可见变更）？
